# 2D 视野遮挡 Demo（Among Us 风格）

纯前端单文件页面，无外部依赖，打开 `index.html` 即可运行。
在线预览：https://huajianluoli.github.io/device-api-test/vision-demo/

- 可见性多边形：向每个墙角发 ±ε 三条射线求最近交点
- 被墙截断的阴影边界**硬切**，仅最远半径那圈圆弧做渐隐
- 暗区是深蓝灰滤镜（房间轮廓仍可辨），亮区叠暖光灯圈
- 三扇可开关的门：关闭时动态插入线段表，视野立刻被截断
- 交互：点击地图瞬移、WASD 接管、E 切门、V 显示射线、G 管理员视角、滑块调半径/暗度/过渡带

本目录为独立新增，不影响仓库原有内容。
